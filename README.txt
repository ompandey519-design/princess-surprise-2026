To publish free with GitHub Pages:
1. Create a GitHub repository.
2. Upload all files and the photos folder.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.

Optional: add a royalty-free MP3 named music.mp3 in this folder for background music.
You can edit the love notes and captions in index.html.
